Guess My Number!

A simple number guessing game built with HTML, CSS and JavaScript. Try to guess the secret number between 1 and 20 before your score runs out!

🎮 How to Play

Enter a number between 1 and 20.

Click Check! to submit your guess.

You'll receive a hint telling you whether your guess is too high or too low.

Each incorrect guess reduces your score by one.

Guess correctly to win and save your highscore!

Click Again! to start a new game.

✨ Features

Randomly generated secret number between 1 and 20.

Feedback indicating whether your guess is too high or too low.

Score decreases with each incorrect guess.

Highscore tracking during the session.

Visual feedback when you win, including a background colour change.

Restart functionality to play again.

🔤 Font

The game uses Press Start 2P, a retro pixel-style font sourced from Google Fonts.

It is imported directly into the stylesheet using CSS @import.
